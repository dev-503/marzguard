# مرزگارد (MarzGard)

> بازنویسی و بازطراحی کامل افزونه دیجیتس (Digits) به عنوان یک افزونه مستقل، سبک و هدلس (Headless) برای وردپرس.

مرزگارد لایه احراز هویت موبایل سایت شما را با معماری مدرن پیاده می کند:

- **فرانتاند Vue 3** (کاملاً جدا از رندر وردپرس) بدون نیاز به Node یا بیلد — Vue به صورت محلی بارگذاری می شود.
- **BackendREST** تمیز و قابل استفاده توسط هر کلاینت (وب، موبایل، اپلیکیشن دسکتاپ).
- **فونت آراد** (Arad Variable) و **دیزاین سیستم سرخآب (Sorkhab)** از آروان: توکن های رنگی، کامپوننت ها، RTL و حالت تاریک.
- **امنیت بالاتر**: ذخیره هش شده کدها، محدودسازی نرخ درخواست، مقایسه ثابت زمانی، هانی پات و کوکی های امن.

---

## ۱. نصب

1. پوشه `marzgard` را در `wp-content/plugins/` کپی کنید.
2. از پیشخوان وردپرس، افزونه **مرزگارد** را فعال کنید.
3. به منوی **مرزگارد → تنظیمات** بروید و درگاه پیامک را پیکربندی کنید.

> در حالت پیشفرض، درگاه `log` فعال است و پیامک ها فقط در لاگ وردپرس ثبت می شوند (مناسب توسعه). برای ارسال واقعی، درگاه `rest` را انتخاب کنید.

## ۲. نحوه استفاده

### شورت کد

```
[marzgard_form]
[marzgard_form mode="register" redirect="https://example.com/account/"]
[marzgard]
[مرزگارد]
```

| پارامتر | مقادیر | توضیح |
| --- | --- | --- |
| `mode` | `login`، `register`، خالی | Bootstrap حالت فرم؛ خالی یعنی مطابق تنظیمات عمومی |
| `redirect` | URL | آدرس هدایت post-login (فقط دامنه همان سایت معتبر است) |
| `class` | class | کلاس اضافی روی المان |
| `skin` | `sorkhab`، `digikala` | انتخاب پوسته رابط کاربری |

### پوسته دیجی کالا (شورت کد)

```
[marzgard_digikala]
[marzgard_form skin="digikala"]
[marzgard_digikala title="ورود به حساب" button_text="ورود" color="#e60023" show_logo="yes"]
[دیجی_کالا]
```

پارامترهای قابل ویرایش: `title`، `subtitle`، `placeholder`، `button_text`، `otp_title`، `otp_button`، `terms`، `color`، `show_logo`، `mode`، `redirect`، `class`.

### ویرایش با المنتور (Elementor)

اگر المنتور نصب باشد، یک ویجت با نام **«مرزگارد — ورود دیجی کالا»** در دسته **مرزگارد** اضافه می شود:

1. در Elementor، ویجت «مرزگارد — ورود دیجی کالا» را به صفحه بکشید.
2. در تب **محتوا**: عنوان، توضیحات، متن اینپوت، متن دکمه ها، متن قوانین، حالت فرم و آدرس هدایت را ویرایش کنید.
3. در تب **ظاهر**: رنگ برند، نمایش/عدم نمایش لوگو و کلاس CSS دلخواه را تنظیم کنید.
4. ذخیره/انتشار کنید — پیش نمایش زنده در ویرایشگر المنتور هم نمایش داده می شود.

> ویجت فقط زمانی بارگذاری می شود که المنتور فعال باشد و هیچ وابستگی خارجی ندارد.

### بلوک گوتنبرگ

بلوک **«مرزگارد — فرم ورود»** در دسته Widgets موجود است و از گزینه Skin هم پشتیبانی می کند.

### جایگزینی فرم ورود وردپرس

در تنظیمات ← عمومی، گزینه **«جایگزینی فرم ورود وردپرس»** را فعال کنید تا فرم مرزگارد در `wp-login.php` نمایش داده شود.

## ۴. REST API

پیشوند: `marzgard/v1` — هدر `X-WP-Nonce` برای درخواست های احرازشده لازم است.

| متد | مسیر | ورودی | خروجی |
| --- | --- | --- | --- |
| GET | `/config` | — | برند، کشورها، رشته ها، ظاهر، تنظیمات OTP |
| POST | `/otp/send` | `phone`+`country_code` **یا** `email`، `purpose`، `website` | `challenge`, `ttl`, `masked`, `channel` |
| POST | `/otp/resend` | `challenge` | `ttl`, `message` |
| POST | `/otp/verify` | `challenge`, `otp`, `remember`, `redirect` | `success`, `user`, `redirect` + تنظیم کوکی ورود |
| POST | `/logout` | — | خروج کاربر |
| GET | `/settings` | — | تنظیمات + نقش های وردپرس (نیاز به `manage_options`) |
| POST | `/settings` | تنظیمات | ذخیره و بازگشت تنظیمات |

نمونه:

```js
fetch('/wp-json/marzgard/v1/otp/send', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'X-WP-Nonce': MARZGARD.nonce },
  body: JSON.stringify({ phone: '9123456789', country_code: '+98', purpose: 'login' })
});
```

## ۵. امنیت

- کد OTP به صورت **هش** (`wp_hash`) در transient ذخیره می شود، نه متن ساده.
- مقایسه با `hash_equals` و شمارش تلاش های ناموفق (قابل تنظیم).
- محدودیت ارسال در ساعت به ازای `IP + شماره` (قابل تنظیم).
- انقضای خودکار کدها و حذف چالش پس از تأیید.
- فیلد هانی پات `website` برای جلوگیری از ربات ها.
- بررسی میزبان آدرس هدایت (فقط همان دامنه سایت).
- شورت کدها و REST از Sanitize توابع وردپرس استفاده می کنند.

## ۵.۱ پروایدرهای پیامک

مرزگارد از چهار پروایدر آماده پشتیبانی میکند:

| پروایدر | تنظیمات لازم |
| --- | --- |
| ملی پیامک (`melipayamak`) | نام کاربری، رمز عبور، شماره فرستنده — متد `SendOtp` |
| فراز اس ام اس (`faraz`) | نام کاربری، رمز عبور، شماره فرستنده، آدرس سرویس (قابل ویرایش) |
| کاوه نگار (`kavenegar`) | API Key، شماره فرستنده |
| SMS.ir (`smsir`) | API Key، شناسه الگوی تأیید، نام متغیر کد (مثلاً `code`) |

علاوه بر اینها، **تمام درگاههای افزونه «پیامک حرفه‌ای ووکامرس فارسی»** (بیش از ۱۰۰ درگاه:Melipayamak، KaveNegar، FarazSMS، SMSIRToken، Asanak، Ghasedak، …) به لیست پروایدرها اضافه میشوند و با انتخاب هریک، کد OTP ورود مرزگارد از همان درگاه ارسال میشود. الگوی پترن هم از طریق فیلد «الگوی پترن» قابل تنظیم است:

```
pattern:12345
code:{code}
```

همچنین دکمه **ارسال تست** در تب پیامک وجود دارد.

## ۵.۲ امنیت

تمام تنظیمات امنیتی در تب **امنیت** قابل مدیریتاند:

- **کپچا:** داخلی (جمع)، Google reCAPTCHA (v2/v3)، Cloudflare Turnstile، آرکپچا.
- **جلوگیری از اس ام اس بمبینگ:** فاصله ارسال مجدد هر شماره پیشفرض **۱۲۰ ثانیه (۲ دقیقه)**، لیمیت ساعتی جداگانه به ازای IP و شماره، حداکثر تلاش تأیید، قفل IP پس از تعداد شکست مشخص.
- **مسدودسازی:** لیست شماره موبایل، ایمیل و IP.
- **سایر:** پنهان کردن خطاهای ورود، لاگ ۲۰۰ رویداد امنیتی، حالت توسعه.

## ۵.۳ قابلیتهای ورود و عضویت

- ورود/ثبت نام با OTP موبایل، ورود با ایمیل و نام کاربری و رمز عبور (قابل خاموش کردن برای مدیران).
- ارسال کد از طریق پیامک، ایمیل، پیام صوتی یا پیامرسان بله.
- ثبت نام خودکار هوشمند، تعیین نقش پیشفرض، تأیید شماره موبایل.
- سازگاری با تسویه حساب و فرم ورود ووکامرس.
- خروجی **Excel (CSV)** و **VCF** از کاربران دارای موبایل (لینکها در تب عمومی).

## ۵.۴ ریتنشن مارکتینگ

تب **ریتنشن** در تنظیمات شامل سه کمپین خودکار است:

- **سبد رها شده:** پس از تاخیر تنظیمشده (پیشفرض ۳۰ دقیقه) با لینک بازیابی سبد پیام ارسال میشود. لینک `?mg_recover=TOKEN` سبد را بازیابی میکند.
- **یادآوری پرداخت:** سفارشهای `pending` / `on-hold` پس از چند ساعت یادآوری میشوند.
- **بازگشت مشتری (Win-back):** مشتریانی که مدتی خرید نکردهاند با کد تخفیف فراخوانده میشوند.

تنظیمات: کانال ارسال (پیامک/ایمیل/بله)، قالب پیامها (`{{site}}`، `{{link}}`، `{{order}}`، `{{coupon}}`)، حداکثر پیام به هر مشتری، ساعات خاموش، و اجرای دستی کمپینها همراه با لاگ ۲۰۰ پیام آخر. کرون هر ۱۵ دقیقه کمپینها را اجرا میکند.

### ۵.۵ پیامک پترن براساس وضعیت سفارش

در ماژول «پیامک ووکامرس» یک تب جدید با نام **«پیامک پترن سفارش»** اضافه شده است.
برای هر وضعیت سفارش میتوان یک الگوی پترن تعریف کرد:

```
pattern:12345
order_id:{order_id}
name:{b_first_name}
status:{status}
```

خط اول شماره پترن و خطوط بعدی متغیرها هستند. متغیرها همان shortcode های
پیامک سفارشاند (`{order_id}`، `{b_first_name}`، `{status}`، `{price}`،
`{all_items}`، `{post_tracking_code}` و…) و پیش از ارسال توسط افزونه پر میشوند.
ارسال تنها زمانی انجام میشود که درگاه انتخابشده از پترن پشتیبانی کند و فیلد
پترن آن وضعیت پر شده باشد؛ در غیر این صورت پیامک متنی معمولی ارسال میشود.
تنظیمات در گزینه `sms_order_pattern_settings` ذخیره میشود.

## ۶. تنظیم درگاه پیامک (REST)

درگاه عمومی با placeholder های زیر کار می کند:

`{to}`، `{message}`، `{code}`، `{api_key}`، `{sender}`

مثال (Kavenegar):

```json
Endpoint: https://api.kavenegar.com/v1/{api_key}/sms/send.json
Method: POST
Body: {"receptor":"{to}","message":"{message}","sender":"{sender}"}
Success path: return.status
```

مثال (Melipayamak الگوی REST):

```json
Endpoint: https://rest.payamak-panel.com/api/SendSMS/BaseSimpleService
Body: {"username":"{api_key}","password":"{sender}","to":"{to}","text":"{message}"}
```

> هدرها و بدنه به صورت JSON معتبرسازی می شوند. در تنظیمات «حالت توسعه» می توانید کد را در پاسخ API هم ببینید — فقط در محیط توسعه فعال کنید.

## ۸. سازگاری با داده های دیجیتس

مرزگارد از همان متاهای کاربر دیجیتس استفاده می کند:

- `digits_phone` → شماره کامل (`+989123456789`)
- `digits_phone_no` → شماره بدون کد کشور
- `digt_countrycode` → کد کشور (`+98`)

بنابراین کاربران قبلی دیجیتس بدون مهاجرت داده قابل ورود هستند. متای اضافی `marzgard_verified` نیز ثبت می شود.

## ۹.۱ ورودی موبایل ایران (PhoneInput)

رابط ورود از یک کامپوننت ورودی موبایل همانند الگوی ارسالی پیروی میکند:

- پیشوند ثابت `+98` در سمت چپ (RTL)، ارقام به صورت `912 345 6789` گروهبندی میشوند.
- ارقام فارسی و عربی (`۰۹۱۲…`) به ارقام لاتین تبدیل میشوند و صفر اول حذف میگردد.
- اعتبارسنجی: دقیقاً ۱۰ رقم و شروع با `۹`؛ پیام خطا: «شماره باید با ۹ شروع شود و ۱۰ رقم باشد».
- تشخیص اپراتور (همراه اول / ایرانسل / رایتل / سایر) و نمایش علامت تأیید سبز هنگام صحت شماره.
- ساختار `Input` با `startAddon` / `endAddon`، حالت خطا (`aria-invalid`) و `Field` + `Label` + `hint` پیاده شده است.

نسخه React/TypeScript همین کامپوننتها برای فرانتاندهای هدلس در پوشه `react/` قرار دارد (`PhoneInput.tsx`، `Input.tsx`، `lib/persian.ts`).

## ۱۰. دمو لاگین ها

در پیشخوان وردپرس، زیر منوی **مرزگارد → دمو لاگین ها** یک گالری با پیش نمایش زنده (iframe) وجود دارد:

| دمو | مسیر | توضیح |
| --- | --- | --- |
| ورود میهن (ایکس کارت) | `dev/mihan/` | پوسته تیره، دکمه سبز ورود |
| ورود اسنپ فود | `dev/snappfood/` | پوسته سبز، دکمه ثابت انتهای صفحه |
| ورود تکنولایف | `dev/technolife/` | پوسته آبی، تب ورود/ثبت نام |
| ورود دیجی کالا | `dev/preview-digikala.html` | پوسته قرمز (همان شورت کد/المنتور) |
| ورود سرخآب | `dev/preview.html` | پوسته پیشفرض مرزگارد + تم تاریک |
| تنظیمات | `dev/preview-admin.html` | رابط Vue صفحه تنظیمات |

هر دمو جریان کامل شماره → OTP → موفقیت را دارد و کد OTP با برچسب «کد دمو» نمایش داده میشود.

برای مشاهده بدون وردپرس کافی است پوشه `dev/` را روی یک سرور استاتیک قراردهید و فایل `index.html` مربوطه را باز کنید.

## ۱۱. ماژولهای داخلی

سه افزونه پیشین به صورت ماژول داخل مرزگارد ادغام شدهاند و نصب جداگانه نیاز نیست:

| ماژول | مسیر | دسترسی |
| --- | --- | --- |
| پیگیری سفارشات (دیارا) | `modules/order-tracking/` | مرزگارد ← پیگیری سفارشات |
| پیامک حرفه‌ای ووکامرس | `modules/woocommerce-sms/` | مرزگارد ← پیامک ووکامرس |
| نصب کننده ایکس کارت | `modules/xcart-installer/` | مرزگارد ← ایکس کارت (نصب) |

تمام پروایدرهای ماژول پیامک ووکامرس در لیست پروایدر مرزگارد هم قابل انتخاب و استفاده برای OTP وروداند.

## ۱۲. تطبیق با پنل آنلاین پیامک و بهینه سازی

پس از تحلیل بسته `onlinepayamak.zip`، بخش های قابل انتقال به مرزگارد اضافه و
بخش های وابسته به ionCube/سرویس ابری/ووکامرس سنگین در نقشه راه قرار گرفتند:

- **تب پیشرفته:** پشتیبان گیری و بازگردانی تنظیمات (JSON، بدون ذخیره رمزها و
  کلیدهای API) + CSS سفارشی که فقط روی فرم های مرزگارد اعمال میشود.
- **تب های لاگ و توسعه و لایسنس:** مشاهده لاگ امنیتی، حالت توسعه و اطلاعات مجوز.
- **بهینه سازی:** کش تنظیمات درون درخواست، بارگذاری مشروط اسکریپت بازیابی سبد،
  حذف نمونه های تکراری ریتنشن، رفع overwrite شدن متغیر سراسری `MARZGARD` و
  اصلاح چندین مورد امنیتی (IP پراکسی جعلی، کپچای ناشناخته، پاک شدن تنظیمات
  با درخواست غیر JSON، مسدودسازی تطابقی و پاک سازی کامل هنگام حذف افزونه).
- **ظاهر پنل:** طراحی مجدد با نوار تب های آبی و ستون راهنما، الهامگرفته از پنل
  سامانه پیامکی. دمو سرخاب نیز اصلاح شد (کشور در سمت چپ، شماره در سمت راست).

جزئیات کامل و جدول وضعیت تک تک بخشها در
